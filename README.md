# Citywide ATM Banking Network

## Project Overview
Designed and implemented a secure multi-branch ATM banking network using Cisco Packet Tracer.

The network connects a central bank headquarters with four remote ATM branches through a shared WAN network.

## Technologies Used
- Cisco Packet Tracer
- VLANs
- Router-on-a-Stick
- OSPF Dynamic Routing
- DHCP
- Extended ACLs
- HTTP, HTTPS and DNS
- WAN Failure and Recovery Testing

## Network Architecture
- 1 Central Bank
- 4 Branch Networks
- 8 ATM End Devices
- 4 Employee PCs
- 1 Primary Bank Server
- 1 Backup Server
- 5 Routers
- Multiple Switches

## Key Features
1. Separate ATM and employee VLANs.
2. Dynamic IP allocation using DHCP.
3. OSPF routing between branches and headquarters.
4. ACL-based employee network restrictions.
5. Centralized banking web server.
6. Backup web server connectivity.
7. WAN failure and recovery testing.

## Project Objective
To simulate a secure and reliable banking network that connects multiple ATM branches to a centralized bank infrastructure.
